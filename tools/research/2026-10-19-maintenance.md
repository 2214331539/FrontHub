# FrontHub 网站维护记录 · 2026-10-19

本次联网检索并核查 108 个候选，收录 100 个；目录从 300 个增加至 400 个。新增 89 张通过画面检查的官网截图，截图总数为 350 张。

## 核查方式

通过设计参考目录发现候选，并逐一请求官方页面，检查页面标题、产品介绍、HTTP 状态、跳转地址与重复项。设计标签和参考说明经过截图核对；未完整呈现的 3D 或动画画面不作为有效封面。HTTP 200 只证明本次请求有响应，不保证每个浏览器都能运行官网。

发现来源包括 [BestSaaSWebDesigns](https://bestsaaswebdesigns.com/)、[Minimal Gallery](https://minimal.gallery/) 与 [Awwwards](https://www.awwwards.com/websites/sites_of_the_day/)。每个收录项的官网、检查时间、HTTP 状态和跳转记录保存在 [核查记录](2026-10-19-candidates.json)。

## 后续更新

1. 使用现有四列格式整理候选文件：名称、官网、标签、参考说明。
2. 运行 `node tools/review-candidates.mjs tools/candidates-日期.txt tools/research/日期-candidates.json`，人工核对响应与归属。
3. 将确认项合入 `tools/catalog.txt`，在 `tools/catalog-meta.json` 记录收录日期与官方来源，再运行 `python tools/make_catalog.py`。生成器会拒绝重复网址和重复 ID。
4. 运行 `npm run audit:embeds`；该命令检查完整目录，不再限制为前 300 项。
5. 使用 `npm run capture -- --all --ids-file=tools/research/日期-added-ids.json --concurrency=3 --wait=7000` 采集本批条目，并检查画面。
6. 运行 `npm run single` 更新单文件；目录更新后重启本地服务，让实时检查同步新条目。
