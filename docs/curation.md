# 页面收录标准

FrontHub 收录可学习的真实 Web 页面。每条记录应让读者知道「它是什么、为什么值得参考、如何找到原作」。

## 收录范围

官网、Web 应用、公开演示、HTML 模板、组件文档、可视化、互动作品及有明确内容的资源集合均可推荐。语言、行业和技术框架不限。

## 基本要求

1. 提供稳定的官方 HTTPS 入口，避免跟踪、推荐返佣链接和无关跳转。
2. 描述具体参考价值，例如导航层级、表格密度、阅读排版、动效反馈或可访问交互。避免只写「很高级」「很好看」。
3. 检查已有记录和最终跳转地址，避免同站重复收录。不同页面只有具备明显不同的参考价值才应独立提交。
4. 标明资源类型、领域、真实标签和核查日期；需要登录的演示应在简介注明。
5. 仓库链接需有官方页面、README 或作者信息佐证；区分页面源码与相关项目仓库。
6. 截图使用真实页面。无法采集时保留缺图状态，不使用验证码、排队页、错误页和占位图。

禁止外部内嵌不影响收录资格。不要绕过 iframe 安全策略、登录、验证码或访问控制。

## 暂缓或不收录

没有可核实入口、仅有宣传而无参考内容、重复内容、失效或售卖域名、恶意及欺骗性页面、缺乏具体说明的推广提交，会暂缓或拒绝。自荐需披露关系，不享有优先权。

暂时网络失败应记录检查环境和时间，不直接认定站点永久失效。停止维护但仍有参考价值的作品可以保留，简介需说明状态；删除或修改 ID 前考虑用户数据兼容。

## 维护记录

批量更新在 `tools/research/` 保存独立日期 / 批次记录，包括候选来源、原始与最终地址、检查日期、采纳 / 暂缓结果、截图复核和限制。记录事实，不把单次 HTTP 200 或 iframe load 事件当作完整可用保证。
